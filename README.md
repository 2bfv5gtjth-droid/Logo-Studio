# Logo Studio

Een app om logo’s, CV’s, posters en meer te maken op je telefoon. Werkt in de browser en kun je op je beginscherm zetten.

Alles staat in `index.html`. Er is geen build nodig. Zet de bestanden in een GitHub-repository en zet GitHub Pages aan.

Let op: de AI-functies werken alleen binnen Claude. In deze versie zijn ze verborgen.
